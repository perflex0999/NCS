# 智能充电桩运营服务平台 — 需求说明

> 本文件是项目唯一的需求基线，所有开发阶段都以本文件为准。

## 一、项目定位

新能源汽车充电桩运营服务平台，统一管理充电站、充电桩、用户订单和设备运行。

一期形态（三端）：
- **H5 用户端**：面向充电用户
- **Web 运营后台**：面向运营 / 运维 / 管理员
- **AI Agent 智能助手**：结合业务数据的智能服务（非简单聊天机器人）

## 二、H5 用户端功能（6 项）

1. **用户登录**：手机号登录（一期用固定验证码 `123456`，不接真实短信）
2. **充电站查询**：附近充电站列表，展示名称 / 地址 / 距离 / 营业时间 / 价格 / 快慢充数量 / 空闲设备数；支持按距离、价格、设备类型筛选
3. **充电站详情**：基本信息、充电桩数量、空闲设备、设备状态、收费标准、停车说明
4. **扫码充电**：扫码进入充电页（一期用「输入设备编号 / 模拟扫码」），设备空闲可开始充电；使用中 / 故障 / 离线不可开始
5. **充电管理**：查看充电状态、充电时间、已充电量、当前费用，可主动结束，结束后自动生成订单
6. **订单管理**：历史订单（订单号 / 充电站 / 起止时间 / 充电量 / 金额 / 支付状态）

## 三、Web 运营后台功能（6 项）

1. **充电站管理**：名称 / 地址 / 所属城市 / 营业时间 / 联系方式 / 运营状态
2. **充电桩管理**：设备编号 / 所属充电站 / 类型（快充 / 慢充）/ 当前状态（空闲 / 使用中 / 故障 / 离线 / 维修中）
3. **订单管理**：全量订单，按用户 / 充电站 / 状态 / 时间范围查询，查看详情
4. **价格管理**：电费 + 服务费，支持分时段定价（白天 / 夜间）
5. **故障管理**：故障设备 / 类型 / 时间 / 描述 / 处理状态
6. **数据统计**：用户数 / 订单数 / 总充电量 / 平台收入 / 设备数 / 故障设备数 + 订单与收入趋势图

## 四、AI Agent 能力（4 项）

1. **用户充电助手**：自然语言咨询，如「附近哪里有空闲快充」「我现在充电多少钱」「我最近一次充电花了多少钱」「附近有吃饭的地方吗」
2. **智能故障咨询**：诊断充电问题（如「为什么我的充电桩无法启动」），查设备 / 订单状态给建议，无法解决则引导提交故障反馈
3. **AI 运营助手**：自然语言查询运营数据（如「今天哪个充电站订单最多」「最近一周收入怎么样」「哪些设备故障次数多」）
4. **AI 运营报告**：自动生成报告（订单 / 收入 / 用户增长 / 设备运行 / 故障）

## 五、系统角色（4 个）

| 角色 | 主要功能 |
|------|---------|
| 普通用户 | 查询、充电、订单、优惠券、AI 助手 |
| 运营人员 | 充电站、订单、价格、运营数据 |
| 运维人员 | 设备和故障处理 |
| 系统管理员 | 用户、角色和系统管理 |

## 六、选定的容量等级：L3（高并发应用级）

**业务规模**

| 指标 | 目标 |
|------|------|
| 注册用户 | 1,000,000 |
| 日活用户 | 100,000 |
| 充电站 | 1,000 |
| 充电设备 | 10,000 |
| 同时在线用户 | 10,000 |

**峰值请求 QPS**

| 业务 | 目标 QPS |
|------|---------|
| 用户登录 | 500 |
| 查询充电站 | 2,000 |
| 查看设备状态 | 1,000 |
| 开始充电 | 300 |
| 结束充电 | 300 |
| Agent 咨询 | 200 |

**设备数据规模**：约 10,000 台设备，高峰每 5 秒上报一次，约 **2,000 条设备数据 / 秒**。

**L3 特殊要求**
- 查询业务不影响核心交易业务
- 设备数据不阻塞订单业务
- Agent 服务不影响核心充电服务
- 单点故障不导致整个系统停止服务

## 七、甲方重点要求

1. 提高用户寻找充电站和使用设备的效率
2. 统一管理充电站、充电桩和充电订单
3. 及时发现和处理设备故障
4. 通过 AI Agent 降低用户咨询和运营数据分析的人工成本
5. 良好的扩展能力（预留预约充电、会员体系、第三方设备接入）

## 八、一期降级约定（无资质时的替代方案）

- **手机号登录**：固定验证码 `123456`，不接真实短信服务
- **支付**：模拟支付，订单状态直接置为「已支付」，不接微信 / 支付宝
- **扫码**：无真实硬件，用「输入设备编号 / 模拟扫码」替代

## 九、技术栈

- **前端**：Vue3 + Vite + Vant（H5）、Vue3 + Vite + Element Plus（Web）
- **后端**：Spring Boot 3 + Spring Cloud Alibaba（多模块微服务）
- **中间件**：MySQL、Redis、RocketMQ、EMQX、Nacos、TDengine（时序，可选）
